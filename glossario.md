
| Termo | Definicao |
| --- | --- |
| UX | Experiência e percepções do usuário ao interagir com um produto, sistema ou serviço. |
| UI | Design	Área relacionada à interface visual pela qual o usuário interage com um sistema. |
| Usabilidade | Facilidade e eficiência com que usuários conseguem utilizar um produto para alcançar objetivos. |
| Teste de Usabilidade | Técnica de pesquisa que observa usuários realizando tarefas para identificar problemas de uso. |
| Think-Aloud | Técnica em que o usuário verbaliza seus pensamentos durante a realização de tarefas. |
| Heurísticas de Nielsen | Dez princípios utilizados para avaliar problemas de usabilidade em interfaces. |
| Eficácia | Capacidade de concluir uma tarefa e atingir o objetivo. |
| Eficiência | Relação entre o resultado alcançado e os recursos utilizados, como tempo e esforço. |
| Satisfação | Percepção subjetiva do usuário sobre sua experiência. |
| Priming | Influência causada pela forma como uma pergunta ou instrução é apresentada ao participante. |
| Acessibilidade | Capacidade de acomodar usuários com diferentes capacidades e limitações. |
| SUS | System Usability Scale, questionário utilizado para avaliar a percepção de usabilidade. |
| CSAT | Customer Satisfaction Score, indicador utilizado para avaliar satisfação. |
